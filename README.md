# 👑 Samrina Boutique - Luxury Ethnic Couture Web Application

A full-stack luxury e-commerce web platform for **Samrina Boutique** built with HTML5, CSS3, JavaScript, Python (Flask REST API), and SQLite Database.

---

## ✨ Features

* **Luxury Royal Emerald & Gold Theme**: 100% Mobile-first responsive modern web design.
* **Dynamic Product Catalogue**: Filter by category (*Pret*, *Luxury Formals*, *Bridal Couture*) and fabric types.
* **Real-Time Currency Switcher**: Live price conversion between **PKR (₨)** and **USD ($)**.
* **Live Search**: Instant dress search filtering as you type.
* **Wishlist & Cart Counter**: Interactive heart wishlist & toast notifications.
* **SQLite Database Backend**: Stores products, categories, stock status, and customer orders.
* **Admin Management Portal (`admin.html`)**: Real-time sales analytics, order management, and inventory controls.
* **Direct WhatsApp Integration**: Pre-filled order confirmation sent directly to boutique WhatsApp (`+92 303 8873030`).

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3 (Vanilla CSS System), JavaScript (ES6+), FontAwesome 6, Google Fonts (`Playfair Display` + `Plus Jakarta Sans`).
* **Backend**: Python 3, Flask REST API, Flask-CORS.
* **Database**: SQLite3 (`boutique.db`).

## 🚀 How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/samrina-boutique.git
   cd samrina-boutique
   ```

2. **Install Backend Dependencies**:
   ```bash
   pip install flask flask-cors
   ```

3. **Run Backend API Server**:
   ```bash
   python server.py
   ```

4. **Launch Frontend Storefront**:
   Open [index.html](file:///c:/Users/Hammad%20Ahmad/OneDrive/Desktop/Samrina's%20Project%20Theory/index.html) directly in any browser or run:
   ```bash
   python -m http.server 8080
   ```

5. **Access Admin Portal**:
   Open [admin.html](file:///c:/Users/Hammad%20Ahmad/OneDrive/Desktop/Samrina's%20Project%20Theory/admin.html) in your browser to view orders and manage products.
